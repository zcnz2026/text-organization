# 剧本对应语系工作台 (Script Language Matcher)

多语种报道剧本自动摘录、逐行时间轴对齐、剧本专用标点转换与 Google 表格分语种写入工具。基于 **Tauri v2 + TypeScript** 构建，支持 **Windows** 与 **macOS** 双系统运行。

## 功能概览

- **界面内加载 Google OAuth 2.0 凭据**：直接拖入或选择从 Google Cloud 下载的桌面客户端 `.json` 文件，点击浏览器一键登录已授权邮箱；令牌在 Windows 通过 **DPAPI**、在 macOS 通过 **系统钥匙串（Keychain）** 本机加密持久保存（支持 Google Sheets API、Google Docs API 与 Google Drive `.docx` 原生三列表单篇读取）。
- **4-Sheet 云端总配置表与团队一键共享**：
  - 点击工作台左侧 **「导出配置模板 (.xlsx)」** 或顶部 **「资源与列配置清单」**，即可生成包含 4 个标准工作表的 `.xlsx` 配置文件：
    1. `1_公共总表与源稿默认列`：统一维护源剧本 `A~L` 默认列、输出表 `【工具提示】` 列（`AUTO` 或指定列字母），以及 5 张多语种公共总表（B1 新常用语表、B2 话在肉身显现单篇摘自表 202210、B3 诗歌 LRC 摘自新版、B4 主祷文多语种总表 202605、B5 报道人名教会名总库）的链接与列号；
    2. `2_各语种资料表链接`：按语种集中维护 C1 六本书目录与单篇链接 Sheet、C3 唯一圣经经文库 Sheet、C4 新俗语表 Sheet、C5 默认诗歌歌词表 Sheet 及摘自补充表链接（支持 `#gid` 精准锁定子表）；
    3. `3_各语种表内列位置映射`：按语种自定义各资料表的表头行号与列字母（含六本书目录 `B~I` 列、单篇 `.docx` 三列表 `1/2/3` 列序、圣经库 `B~E` 列、新俗语表 `F/G/I/J` 列、诗歌表 `A~C` 列）；
    4. `4_各语种剧本标点规则`：内置 28 个语种的剧本专用外层双引号、内层嵌套单引号、撇号、截取省略号（`[…]` / `(…)` / `...` / `……`）与专属句末句号字符（如 `।` / `។` / `။`）。
  - 将该 `.xlsx` 上传到 Google Drive 并转为 Google 表格后，全组同工只需粘贴这一条 **「云端总配置表链接」** 并点击 **「刷新云端配置」**，即可同步全套语种链接、列映射与标点规范。
- **全表列位置可视化自定义**：
  - **源剧本与输出列位置设置 (`A~L`)**：支持「优先按表头列名自动识别」或按固定行号与列字母读取非标源稿，支持从当前已加载剧本一键读取首行表头预览。
  - **本期诗歌子表智能匹配**：输入当期关键字（如 `39期.葡萄牙` 或 `39期`）即可自动在各语种诗歌表内锁定对应子表，也支持为单个语种临时指定本期诗歌子表链接。
- **8 类内容自动提取与逐行对齐**：
  1. 固定引导词（`全能神说：` 等）；
  2. 大段神话单篇检索与逐行时间轴语义切分（兼容 Google Docs 与 Google Drive `.docx` 三列表，自动忽略 `<w:del>` 修订删除内容、兼容英文第二列 `You(s)` 匹配，并识别 `有省略` 与 `涉及截取`）；
  3. 双排摘自格式匹配（区分 `字幕带版` 与 `视频特效括号版`，支持 B2/B3 公共摘自总表与 C1 六本书目录 `H/I` 双列摘自，自动兼容韩语等单排通用语种）；
  4. 教会诗歌与神话语诗歌歌词及出处（自动区分 `神话诗歌标题：` 与 `教会诗歌：` LRC 多子行歌词，支持 `1..5` 个连续 LRC 子行自动聚合对齐至剧本单行）；
  5. 单一圣经库检索（严格隔离版本，查不到直接标红提示，**绝不自动混查天主教圣经库**）；
  6. 新俗语表 / 撒但毒素匹配（兼容 `/` 多写法词条与漏标兜底）；
  7. 各语种定稿主祷文自动填入（支持 `A列=语种、B列=整段主祷文` 单格全文自动按剧本 8 行切分并将末尾 `Амінь!` / `¡Amén!` 对齐至 `阿们！` 行）；
  8. `Note` 列 `XX` 占位符预填、独立标题行双填，以及报道人名/教会名/国家名库（最新期号优先）预填。
- **多语种批量写入专用输出 Google 表格**：每个语种独立生成一个工作表（Sheet），已匹配标浅绿、需核对标浅琥珀、未找到标浅珊瑚红，并在最右侧（或指定列）附加 `【工具提示】` 列；同时支持一键导出本地 `.xlsx` 多工作表备份。

## 快速启动

### 方式一：正式安装包（免环境，适合日常分发给 Windows / Mac 同工）
推送版本标签（如 `v0.2.0`）到 GitHub 后，GitHub Actions 会自动在 Releases 页面生成：
- **Windows**：`.exe` / `.msi` 安装包（双击即用）
- **macOS**：`.dmg`（通用架构，同时兼容 Apple Silicon M 系列芯片与 Intel Mac）
  > macOS 首次打开未签名应用如遇拦截，可在终端运行：`xattr -cr "/Applications/剧本对应语系工作台.app"`

### 方式二：本机免 Rust 秒开模式（开发调试 / 本机有 Node.js）
- **Windows**：双击 `启动工作台-Windows.bat`（或运行 `npm start`）
- **macOS**：双击 `启动工作台-macOS.command`（或运行 `npm start`）

## Google OAuth 2.0 授权配置说明

1. 在 Google Cloud Console 中启用 **Google Sheets API**、**Google Docs API** 与 **Google Drive API**（用于读取云端硬盘上的 `.docx` 原生三列表单篇文档）。
2. 在「凭据 (Credentials)」中创建 **OAuth 客户端 ID**，应用类型选择 **桌面应用 (Desktop app)**，下载 `.json` 文件。
3. 打开软件顶部 **「Google OAuth 授权」**，选择该 `.json` 文件并点击「打开浏览器登录 Google 账号」，登录已有源稿/资料库查看权限及专用输出表编辑权限的邮箱即可。

## 目录结构（模块化架构）

```text
src/
├── types/          # 领域模型、全表列映射配置 (schema-config) 与全局状态类型定义
├── platform/       # 宿主通信桥接层（自动适配 Tauri IPC 与本地 Node 桥接）
├── google/         # Google URL/gid 解析、Sheets v4 读写着色、Docs v1 与 Drive .docx 三列表提取
├── catalog/        # 28 语种标点预设、4-Sheet 云端配置模板生成/解析与各类资料库解析加载
├── engine/         # 剧本行分类器、文本匹配、LRC 聚合、逐行切分、标点规范化、主流水线与 XLSX 导出
├── ai/             # Gemini API 密钥池轮换与结构化输出客户端
└── ui/             # 简体中文双栏工作台组件、源稿列设置弹窗、资源配置中心与明暗自适应样式
server/             # 本地免 Rust 秒开桥接服务（OAuth 回环监听 + DPAPI/Keychain 加密存储）
src-tauri/          # Tauri v2 原生桌面壳（Rust）
tests/              # 核心解析器、4-Sheet 配置往返、28 语种标点与真实 39 期剧本端到端自动化测试
```
